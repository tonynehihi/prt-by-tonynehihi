# Changelog

## Premiere by Tonynehihi 1.1.0

First release of Premiere by Tonynehihi (PrT), a personal build based on FilmCraft 0.8.0 by the ArtCraft team.

**NEW NAME AND ICON:** the app is now "Premiere by Tonynehihi" (bundle `PrT.app`) with the suite's Adobe-style icon.

**SELF-UPDATE IN THE APP:** PrT checks GitHub for a newer version at launch and shows the release notes in a popup; you can also check any time via Help → Check for Updates or the About dialog. On macOS it can download, build and install the update in place.

**NO UPSTREAM LINKS:** the ArtCraft Discord button, website/GitHub links and the upstream docs links are removed from the header, Home screen, Help menu, settings and shortcuts panel. FilmCraft is credited in the About dialog and in the README.

**FULL FILMCRAFT 0.8.0 VIDEO EDITOR:** the complete non-linear editor — timeline editing, effects, colour, audio, export — unchanged under the hood.

— tonynehihi
